# 定应期

在空的 SQLite 数据库执行项目根目录的 `gua.sql`。已认卦后，以本卦全名查询 `SELECT * FROM hexagram_board WHERE name = ? ORDER BY position`，参数绑定卦名，初爻为 1、上爻为 6。已有本次查询结果时直接复用。

主事爻用第②步定的用神（自占多为世）；旺衰、空破、动静、变爻取自第③、④步。冲、合、值查 `SELECT * FROM branch_interaction WHERE target = ? AND (chong = 1 OR he = 1 OR same_branch = 1)`；长生、帝旺、墓、绝查 `SELECT stage, branch FROM changsheng WHERE element = ?`；出旬日期按 jiazi 的 seq 顺推到下一旬。

## 操作

按主事爻状态取应期（各门类应期总注章）：静而逢值、逢冲；动而逢值、逢合；太旺者逢墓、逢冲；衰绝者遇生、遇旺；入三墓者待冲开；逢六合者待冲开；月破待填实之月日或逢合之日；旬空待出空、填实或冲空之日；大象吉而受克，待克神受克之日；大象凶而受克，防克神逢生之日，克神逢值、当令之月日亦应（面圣上书章大壮之夬：为名以官寅木为用，申金忌神动化酉进神，八月酉金当令削职）；化进神逢值、逢合；化退神忌值、忌冲；世空原神动，待原神逢值；世衰原神静，待原神逢冲。也可应在动爻或变爻之支。自占求财、借贷，用神静而世爻动者，可取世爻逢值、逢合之日（求财章借贷得晋，世动逢合，辰日得财）。近病逢空即愈，出空之日愈；久病逢空反凶（两现章化空注、旬空章）。天时多应在时辰：子孙或财化出之时晴，父母逢值、逢冲之时雨（天时章诸例）。

远事定以年月，近事应于日时；占远亦有应近、占近亦有应远。卦不明时再占一卦合断，不妄定期。书中例证：出空日应（甲寅日出空得财）、冲去伤爻之日应（子日冲午得见）、冲去合神之日应（丑日冲未起床）、实破之年月应（巳年承袭）、破而逢合之日应（卯日得信）、用神墓月应（木墓于未，六月病）、冲开墓库之年月应、用神旺地之日应（辰土旺于子，子日起床）。

## 输出与排错

输出主事爻、所据状态、候选应期（支及其理由，近事给日、远事给月年）及首选。多个条件并存时说明取舍；缺日干无法推旬空出空时注明。应期只是传统推法，交代条件而不作保证。

每条候选应期须提交一条 `topic: "window"` 判断，字段：`branch`（十二支）、`unit`（日/月/年）、`channel`（值/合/冲/填实/冲墓/当令/克神受克/化出之支值）。程序按同一 `branch+unit` 汇总通道并计算置信度；勿手填 confidence。询问应期且本步 accepted 时至少一条 window。
