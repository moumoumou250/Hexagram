# 按问题取用神

在空的 SQLite 数据库执行项目的 `database/gua.sql`。已认卦后，以本卦全名查询 `SELECT * FROM hexagram_board WHERE name = ? ORDER BY position`，参数绑定卦名，初爻为 1、上爻为 6。已有本次查询结果时直接复用。

`context.database.v_yong_candidates` 可查本爻、变爻、伏神、月建和日辰。先按所问选六亲，再依盘面比较；`is_selected` 只标记已提交的主用神。爻层候选可提交 `record_judgment` 到 `yongshen_judge`，字段为 `select_reason`。 查询库不可用时，继续使用本次 Markdown 和已有查表证据。

在固定盘的 relative 列筛选所取六亲，按 position 列出候选爻，以 shi_ying 辨世应。定用神后查 `SELECT yuanshen, jishen, choushen FROM yongshen_roles WHERE yongshen = ?`，再在盘上找出各自的爻位：原神生用神，忌神克用神，仇神克原神而生忌神（用神元神忌神仇神章，书作“元神”）。动静、月日取自本次盘面。

## 操作

先提取问题中的对象与所求结果，按用神章取六亲：父母为尊长师长、文书契约、房屋车舟衣服，一切庇护我者；官鬼为功名官府、妻占夫、鬼神盗贼，一切拘束我者；兄弟为兄弟姊妹同辈，占财为劫财、谋事为阻隔；妻财为妻妾仆役、货财器物，一切我所使用者；子孙为子女晚辈、医药僧道兵卒、六畜，为福德、制鬼、解忧之神，独占功名忌之。自占看世；问本人处境兼看世。所问之人与我无亲属名分时看应，如延师以应为用（六冲章例）。“身”即世爻，不用卦身（题头总注章）。问能否获聘取官鬼，问这份工作的薪酬看妻财，问书面合同看父母。一个问题牵涉多项时，依用户最关心的结果定主次。

天时：占雨看父母，占晴看子孙，妻财亦主晴而力逊子孙；官鬼为雷电雾，兄弟为风云；世应不作晴雨之用，须指明地方与所求（天时章）。婚姻：男家占女、男自占妻以财为用，应为女家或女身；女家占男以官为用，应为男家（婚姻章）。坟地：世为穴、为本地，子孙为后裔，以世与子孙为主，父母兄弟财官各事另占，不在一卦兼断（寻地章、占地形势章）。上书、献策、条陈意在求名者以官为用，父母文书只是手段，父旺官衰亦无用（面圣上书章大壮之夬）。代人占功名难取用神，宜本人亲占（卦变生克墓绝章，代卜长辈功名例）；一念只占一事，两事同问或代人举念时，卦常应其中一念，取用不明即再占（两现章，求财与丈人病两卦、家人代占防害例）。

用神两现时，古法舍休囚取旺相、舍静取动、舍破取不破、舍空取不空、舍伤取不伤；野鹤验得多应在旬空、月破之爻，应期也常落在其填实之日（两现章）。临月建、日辰者优先（用神章例：三重父母取临月建之辰土）。

用神不上卦时，先看月建、日辰是否即用神，是则以日月为用神，不必寻伏神（月将章、飞伏神章）。否则查 hidden_relative、hidden_branch，注明伏神与同位飞神。飞神生伏为有用，飞神克伏为受制；飞神旬空、伏神易出（飞伏神章）。飞爻、变爻都没有用神，才寻伏神；变爻出现的用神可以参用（飞伏神章引黄金策及诸例）。伏神仍难定时，野鹤宜再占一卦求用神明现，不从互卦、天干合化里另找用神（飞伏神章李我平按）。

## 输出与排错

输出问题、所取六亲、候选爻位、主用神及取舍依据，以及原神、忌神、仇神的爻位（不上卦的注明）。同类两现时结合所指对象、世应、动静、空破和月日说明主次；资料不足可暂留并列。用神伏藏时写明伏神干支五行、飞神干支五行和飞伏生克。
