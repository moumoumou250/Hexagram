# 用神解读（EL15）

本 Skill **不进入** `identify → … → synthesis` 步骤链，也不写入 `RULE_FILES` 指纹。  
它只在汇总之后、导出 HTML 时，把已冻结的 facts / forces / windows 填进 `rules.json` 模板。

## 范围

- 只说用神、原神、忌神、世应相关结构。
- 盘面要点含：日月对用神/世/应的结构句、两动以上动爻彼此互作、每位明动与同位变爻对照。
- 不说所问事情的结局（升职、复合、病愈等）。
- `question` 只用于取用神，不写进解读故事。

## 操作

1. 读取 `config.json` 的 `enabled_blocks`。
2. 用程序命中（路线 A）或汇总提交的 `rules_fired`（路线 B）得到条目列表。
3. 按模板生成短句：先结论，后原因；术语带白话。
4. 导出前自检：无事项禁词；主语是用神侧；争议条目标「需核对」。

## 输出

- 页面顺序：首屏一句（`headline`）→ ① 用神盘面要点（按对象分组）→ ② 六爻判断表 → ③ 判断摘要（原文折叠）→ 应期 → 分层与证伪。
- 应期只写通道与置信度，不写「某日事必发生」。

## 表格取数与词表

- **只读、不写业务表**；不进规则指纹。
- 动变优先读冻结 `evidence.moves` 的 `change_board`；世应冲合由 `view.build_data.pair_links` 查表（不进 `_board()`）。
- 力度词表：用神 `旺/有气/衰而有救/衰/无用`；原忌仇 `有力/无力/中和`；世应第 12 列固定 `—`。
- 权威字段空则按 overall+根基派生并标「派」，否则写「待核」；结构上没有的项写 `—`。

## 排错

- 旧记录无 `rules_fired`：现算命中并标注「按当前配置派生」。
- 条目与盘面不符：以 facts / forces 为准，丢掉该条 `rules_fired`。
