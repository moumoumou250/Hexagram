## 一、gua.sql 新增

**`hexagram_transition`，本卦 + 动爻组合 → 变卦，4096 行。**
- 主键：（hexagram_id, move_mask）。move_mask 取 0–63，初爻 = 1、二爻 = 2、三爻 = 4、四爻 = 8、五爻 = 16、上爻 = 32；0 为静卦。
- 内容：变卦、动爻数、动爻位（'1,2'）、内外卦是否变、六冲六合的变化、内外卦反吟伏吟、八纯卦卦变生克。`l1..l6` 由 move_mask 自动生成。
- 约束：(hexagram_id, changed_hexagram_id) 唯一，静卦的变卦等于本卦，动爻数、动爻位、内外卦标志都必须与 move_mask 一致。
- 写入触发器：变卦必须是本卦按 move_mask 翻爻所得；六冲六合变化、反吟伏吟、卦变生克必须与 `hexagrams`、`trigram_fanfu`、`trigram_change` 一致。禁止 UPDATE。

**`moving_line_change`，每个动爻一行，12288 行。**
- 主键：（hexagram_id, move_mask, position）。外键连到 `hexagram_transition` 和 `hexagram_lines`。
- 本爻：阴阳、干支、五行、六亲。
- 变爻：阴阳、干支、五行，变爻六亲按本卦宫五行（动变章）。
- 关系：huitou（回头生、回头克、比和、动生变、动克变）、化冲、化合、进退神、化长生帝旺墓绝、爻伏吟，以及生成列 `line_fanfu`（反吟 / 伏吟）。
- 约束：只存动爻；阴阳必须翻转；五行随地支；伏吟标志等于“本支 = 变支”。
- 写入触发器：动爻位必须在 mask 内；本爻必须等于 hexagram_lines；变爻必须等于变卦同位爻；变爻六亲必须按本宫算。禁止 UPDATE。

**视图。**
- `hexagram_change`、`change_board` 改为读这两张实表。v2 的旧列名、列顺序和取值都不变：与 v2 现算视图整表双向比对，0 差异。
- 末尾新增列。`hexagram_change`：move_mask、l1..l6、inner_changed、outer_changed。`change_board`：move_mask、changed_polarity、line_fanfu、shi_ying。
- 旧列 `moving_mask` 仍是 6 位文本，从初爻写到上爻（如 '110000'）；新列 `move_mask` 是整数（同例为 3）。

**`integrity_issues` 新增三类检查：**
- 每卦组合数是否为 64；
- 每个组合的动爻行数是否等于动爻数；
- 关系列（回头、冲、合、进退、长生位）与规则表现推的结果是否一致。

正常为 0 行。

## 四、与方案的出入

1. **`gua.sql` 比估计的大。** 方案估约 1.0–1.3 MB，实际 1.86 MB。原因是每卦加了一行注释、每条 INSERT 都写出列名，加上中文按 UTF-8 每字 3 字节。建成的库 1.77 MB，在方案 1.2–1.8 MB 的范围内。
2. **动爻触发器多一道检查。** 触发器先于 CHECK 执行，所以 `moving_line_change_check` 第一条加了“爻位不在 move_mask 内”的检查，报错更明确。CHECK 仍然保留。
3. **兼容比对的做法。** 方案写的是在测试里保留 v2 视图并改名 `_v2`；实际直接用 `Jingfang-v2/gua.sql` 建一个 v2 库再 ATTACH 比对，效果相同，而且覆盖了全部对象。
4. **v2 反向测试的前置。** v2 的反向测试要删原表行，现在新表的外键引用这些行，所以测试前先在回滚点内清空两张新表，测试内容不变。
5. **`oracle_v2.py` 被替代。** 它的全部内容已并入 `oracle_v3.py`，所以 v3 目录里不再单独保留；v2 包里仍有。

## 四、流派与版本上的未决问题
1. **土的长生**：本书取土随水（申子辰巳）。《卜筮正宗》等也取此说，但子平、星命家多用“戊土寅、己土酉”或“土随火”，李我平按语中驳过这些说法。库里按本书取。
2. **进神是否含“戌化丑”**：1925 本只列七对，许多通行本、他书有八对（加戌化丑、丑化戌）。库里按 1925 本。若要补，只需在 `jin_tui` 加两行。
3. **三刑**：1925 本作“丑戌相刑、未辰相刑”，没有“申刑寅”，与通行的“丑戌未、寅巳申”不同，疑为刻误。库里照原文录入并加注；书中唯一的验例（寅月庚申日巳爻）恰好是寅巳申。
4. **卦反吟**：反伏章的卦变反吟只举了“乾变坤”，乾坤地支逐位并不相冲。爻变、内外卦反吟的书例（升之观、观之坤、巽之观、比之井、临之中孚）都是巽坤互变、三支逐位相冲。库里只按“三支逐位相冲／相同”入表，“乾变坤”一类卦变反吟的通则书中没有说明，留待人工判断。《卜筮正宗》等以后天方位相冲（乾巽、坎离、艮坤、震兑）论卦反吟，与本书书例不同。
5. **卦变生克**：书例都是八纯卦互变，所以 `gua_change` 只对纯卦→纯卦给值。单个内卦或外卦变化时是否也论卦变生克，书中没有明言。
6. **四时旺相**：本书只分旺、相、休囚（另注余气），不用“死”。他书的“旺相休囚死”五分法没有采用。
7. **六神**：表照录；野鹤主张六神不决吉凶，skill 里只作辨事参考。
8. **原文自身疑点**：卦例 #6 日辰前后不一，#12“子财落空亡”与旬空不合，见 CASES.md 第三节。
