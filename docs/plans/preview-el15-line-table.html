动爻初爻 巳火 官鬼 明动

结构两动 · 变爻 说明

用神二爻卯木于酉月休囚，又被月建酉金冲为月破，兼值旬空，本身无气；所幸日辰亥水生卯、卯长生于亥，为有根之衰。世爻未土休囚受日克，用神克世，用与世直接相接。原神四爻亥水临日辰、酉月为相，旺相有力，本可生用；但用神旬空，空不受生，须待出空。忌神五爻酉金临月建而旺、又明动，虽化申金退神，占近事旺相不退，克用之力仍在。

本页只分析用神及相关爻的力量与条件，不对所问具体事情作结果预言，以免误导。应期只给通道，不给保证。
