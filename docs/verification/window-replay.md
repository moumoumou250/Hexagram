## 用法

1. 对新解或书例回放，timing 提交对应 `window` 条目。
2. 看 `windows` fact：同支同单位多通道 → `high`，单通道 → `candidate`。
3. 与上表书中应验支比对，`diff` 写入本文件备注列，作为通道规则反例。
4. 「当令/填实」缺失仅告警，不阻断提交。
