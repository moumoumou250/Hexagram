# 《增删卜易》卦例研读笔记（CASES）

来源：1925 年上海文明书局石印本（秦慎安校，国家图书馆藏、Wikimedia Commons 公有领域扫描，本机 `/workspace/zengshan/book.pdf`）为底本；卦图文字取自维基文库《增刪卜易》录文（公有领域），逐卦用 `gua.sql` 核对，和 1925 本有出入处已目验原刻页。下表的断语、结果和经验都是我按原文概括的，没有用孙正治 2012 年译本。

共读 53 个卦例：卷一第九至第又二十六章 37 个，卷二月破、飞伏、进神退神、随鬼入墓、独发诸章 16 个。其中 #33–34、#35–36 两组，以及 #38、#42 两例内含的再占卦，都是“再占合断”的连卦。每例的“核对数”= 1（由动爻推变卦，与书中卦名核对）+ 可查表的断语要点条数，全部由 `verify/cases/cases_check.py` 自动核对。

## 二、成功经验总结

**1. 取用神**
- 用神两现时，取临月建或旺相的那一爻（#1，三重父母取临月建的辰土）。野鹤又说，应期多落在旬空、月破那一爻的填实之日（两现章）。
- 用神不上卦时，先看月建、日辰是不是用神；不是，再找伏神。飞神生伏为有用（#42），飞神旬空则伏神容易出现（#41），伏神空又被飞神克就是真无（#34）。
- 野鹤更看重“多占”：再占一卦，让用神明现，胜过专凭伏神（#33–36、#38、#42）。
- 自占看世（#3、#14），占无亲属名分的人看应（#25）。功名占最忌子孙化进、官化退（#44）。

**2. 旺衰以月日为纲**
- 克少生多为吉（#7、#13）。用神无根（月破又受日克）时，原神再有力也生不起（#3）。
- 月建入卦动作忌神，祸更深（#11）。临日辰虽然不破，但四重土来克，寡不敌众（#15）。
- 当时旺相、过时受害的，应在用神入墓之月（#12）。

**3. 神兆机于动**
- 动爻逢日冲不散（#2、#29）。月破、旬空的爻只要动，照样有用，应在实破、出空、逢合之时（#38、#39、#45、#48）。
- 暗动的原神能解明动忌神之克（#6、#28）。旺相静爻被日冲为暗动，更有力（#43）。
- 动而逢合是被绊住，要等冲开（#1、#18）。

**4. 看变爻**
- 化回头生能救（#4、#29、#36）。化回头克多凶（#9、#14、#30、#44），应在冲去克神之日或克神当令之时。
- 化回头冲不等于回头克，要看五行（#23）。
- 进神退神要看旺衰：动变都旺，近事不论退（#46）；退神得日生也不退（#47）；化空、化破照样能进（#45、#48）。
- 化绝、变鬼为凶，青龙也救不了（#16）。
- 入墓不一定凶：世旺入墓、墓神被破都不是真墓（#49–51）；休囚被克而入墓才是真墓（#52）。

**5. 卦级**
- 六冲变六合，可以不看用神，直接断吉（#19）；六合变六冲，先合后离（#25）；冲变冲主散（#21、#26）。
- 反吟主反复：用神旺相，事情照样成（#31）；用神化回头冲克则大凶（#30）。伏吟主忧郁，难以动身（#32）。
- 八纯卦“化去不克”，仍须看爻（#26）。

**6. 旬空**
- 在旬内毕竟为空，月建也填不了（#8），出空之日应（#8、#22、#40）。日辰冲空则当日应（#22）。
- 用神旬空躲不过克，出空就受伤（#47）。吉凶不明时再占合断（#33–36）。

**7. 应期规律（按例统计）**
- 出空、填实、冲空之日：#2、#8、#22、#36、#39、#40、#45、#48、#49。伏神逢值之日：#41。
- 冲去克神或合神之日：#1、#3、#9、#13。
- 实破之年月：#38。破而逢合之日：#39。动而逢合之日：#53。
- 用神墓月：#12、#47。冲开墓库：#50。用神旺地之日：#37（土旺于子）。
- 克神当令之月：#14。静爻逢冲之年：#24。用神所化之支：#18。

**8. 辅助项只作附和**
- 六神不定吉凶（#16、#17）。
- 三刑野鹤数十年只验到一卦（#27）。
- 独发、独静只能参考，不能代替用神（#53）。
